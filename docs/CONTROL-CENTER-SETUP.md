# راه‌اندازی سریع — از صفر تا اولین پروپوزال تاییدشده

این فایل فقط کارهایی است که **شما** باید انجام دهید؛ هر چیز دیگری در کد آماده است.

## ۱) دیتابیس

داشبورد روی پایگاه‌دادهٔ همین پروژه (`DATABASE_URL` روی Vercel) کار می‌کند.
فایل `supabase/migrations/0004_control_center.sql` را یک‌بار روی همان دیتابیس اجرا کنید:

```bash
npm run db:push          # با DIRECT_URL
# یا: SQL editor سوپابیس → محتوای فایل را paste و Run کنید
```

اگر می‌خواهید ایجنت کشف پروژه در **پروژهٔ Supabase دوم** کار کند، همین فایل را آنجا هم اجرا کنید؛
داشبورد خودکار تشخیص می‌دهد و از صفحهٔ `/control/settings` می‌توانید پروژه‌های تازه را منتقل کنید.

## ۲) تلگرام

| مقدار | از کجا |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → `/newbot` |
| `TELEGRAM_CHAT_ID` | به ربات `/start` بدهید؛ خودش شناسهٔ چت را می‌فرستد |

روی Vercel هر دو ست شده‌اند. بعد از دیپلوی یکی از این دو کار:

- در `/control/settings` دکمهٔ **ثبت وب‌هوک** را بزنید (آدرس دامنهٔ فعلی خودکار تشخیص داده می‌شود)، یا
- دستی:

```bash
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook?url=https://<YOUR-DOMAIN>/api/telegram-webhook"
```

سپس **ارسال پیام آزمایشی** را بزنید.

## ۳) اولین پروژه

بعد از ورود با حساب ادمین:

1. `/control/projects` → **پروژه جدید** → متن آگهی کارفرما را بچسبانید.
2. ایجنت همان لحظه پروپوزال فارسی/انگلیسی می‌نویسد و کارت آن به تلگرام می‌رود.
3. در تلگرام **✅ تایید و ارسال پیشنهاد** را بزنید → وضعیت پروژه `proposal_sent` می‌شود.
4. وقتی کار را گرفتید: **🤝 کار گرفته شد** → سپس از تب «ابزارهای خودکار» اسکلت/ترجمه/اسلاید بسازید.
5. در پایان: **🏁 تکمیل و تسویه** → تراکنش USDT ثبت می‌شود.

## ۴) اختیاری اما توصیه‌شده

| متغیر | نتیجه |
|---|---|
| `OPENAI_API_KEY` | پروپوزال‌ها و ترجمه‌ها با مدل زبانی نوشته می‌شوند (بدون آن، قالب هوشمند + واژه‌نامهٔ داخلی) |
| `CRON_SECRET` | امکان اجرای حلقهٔ ایجنت از بیرون (`/api/control/agent/cron?secret=…`) |
| `APP_URL` | لینک‌های داخل پیام‌های تلگرام به دامنهٔ ثابت اشاره می‌کنند |
| `SUPABASE_SERVICE_ROLE_KEY` | خواندن/نوشتن در پروژهٔ Supabase دوم حتی با RLS |

> روی پلن Hobby ورسل، Cron فقط **یک‌بار در روز** اجرا می‌شود (برنامه در `vercel.json` روزانه است).
> برای پایش مداوم از n8n/Make یا لینوکس cron با `CRON_SECRET` استفاده کنید.
