# راه‌اندازی کامل از داخل داشبورد — بدون دست زدن به Vercel

همهٔ اطلاعات حساس (توکن تلگرام، آدرس و کلید Supabase، آدرس کیف پول تتر) از یک
**فرم گرافیکی** در `/control/settings` گرفته می‌شوند و رمزنگاری‌شده در جدول
`app_settings` ذخیره می‌شوند. متغیر محیطی اگر وجود داشته باشد اولویت دارد
(برای چرخش سریع کلیدها بدون دیپلوی).

## ۰) پیش‌نیاز: یک‌بار دیتابیس

فقط همین دو فایل را روی دیتابیسی که `DATABASE_URL` به آن اشاره می‌کند اجرا کنید
(SQL Editor سوپابیس یا `npm run db:push`):

```
supabase/migrations/0004_control_center.sql
supabase/migrations/0005_app_settings.sql
```

## ۱) ورود به پنل

`https://<your-domain>/admin` → ورود با حساب مدیر → از سایدبار «مرکز کنترل ایجنت».

## ۲) تب «تنظیمات» (`/control/settings`)

| فیلد | از کجا | نکته |
|---|---|---|
| توکن ربات تلگرام | @BotFather → `/newbot` | با ذخیره، خودکار تست می‌شود |
| شناسه چت تلگرام | به ربات `/start` بدهید | عدد، مثلاً `7590237754` |
| آدرس سایت | دامنهٔ Vercel | خالی بگذارید = دامنهٔ فعلی مرورگر |
| آدرس Supabase | Project Settings → API → URL | `https://xxxx.supabase.co` |
| کلید عمومی Supabase | همان صفحه (Publishable/anon) | برای Realtime |
| کلید سرویس Supabase | همان صفحه (service_role) | فقط اگر داشبورد باید در پروژهٔ دوم بنویسد |
| آدرس کیف پول USDT | کیف پول TRON خودتان | با `T` شروع می‌شود، ۳۴ کاراکتر؛ در تب «کیف پول» هم دیده می‌شود |

سپس:

1. **ذخیره تنظیمات**
2. **ثبت خودکار وب‌هوک** → سایت خودش `setWebhook` را روی
   `https://<domain>/api/telegram-webhook` صدا می‌زند
3. **پیام آزمایشی** → اگر پیام در تلگرام آمد، اتصال کامل است

> مقادیر حساس با AES-256-GCM رمز می‌شوند (`APP_ENCRYPTION_KEY` یا کلیدی مشتق از
> `DATABASE_URL`) و در پاسخ API فقط به‌صورت `9095••••••LfAA` برمی‌گردند.

## ۳) اولین پروژه

`/control/projects` → **پروژه جدید** → متن آگهی را بچسبانید → ایجنت پروپوزال
می‌نویسد و کارت آن با دکمه‌های «✅ تایید و ارسال پیشنهاد / ❌ رد پروژه» به تلگرام می‌رود.
هیچ چیزی بدون تایید شما برای کارفرما ارسال نمی‌شود.

## ۴) کاوش خودکار پروژه (اختیاری)

اگر ایجنت کشف پروژه در یک پروژهٔ Supabase جدا کار می‌کند، همان `0004` + `0005` را
آنجا هم اجرا کنید، آدرس/کلیدش را در تنظیمات بگذارید تا کارت «وضعیت پایگاه‌داده»
سبز شود و دکمهٔ «انتقال پروژه‌های جدید» در تب پروژه‌ها فعال شود.

## ۵) زمان‌بندی

روی پلن Hobby ورسل، Cron روزانه است (`vercel.json`). برای بازه‌های کوتاه‌تر از
n8n/Make/لینوکس با `GET /api/control/agent/cron?secret=$CRON_SECRET` استفاده کنید.
