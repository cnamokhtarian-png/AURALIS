# ایجنت فروشگاه AURALIS — راه‌اندازی، کانال‌ها و چک‌لیست داده

سه ایجنت به‌هم‌پیوستهٔ **تحقیق بازار / بازاریابی و محتوا / فروش و CRM** روی همین پروژه ساخته شده‌اند.
همه‌چیز داخل داشبورد `/control/store` است؛ هیچ سرویس پولی، دیتابیس دوم یا ابزار بیرونی لازم نیست.

| ایجنت | کار | ورودی | خروجی |
|---|---|---|---|
| 🔎 تحقیق بازار | گزارش رقبا، قیمت، ضعف‌ها، ترند | متنی که خودتان از بازار/نظرات دارید + جستجوی وب اختیاری | `research_reports` + پیشنهاد زاویهٔ تمایز |
| 📣 بازاریابی و محتوا | کمپین، کپشن هر کانال، تقویم انتشار | برند، پیشنهاد، مخاطب هدف | `campaigns` + `marketing_posts` |
| 💬 فروش و CRM | پاسخ مشتری، پیام اول شخصی‌سازی‌شده، پیگیری، امتیاز سرنخ | پیام ورودی / سرنخ دستی / ایمپورت CSV | `leads` + `store_messages` + تایم‌لاین |
| 🧠 ارکستراتور | هر بار فقط کارهای «سررسیدشده» را انجام می‌دهد | کرون | خلاصه در تلگرام |

## قواعد ثابت (ضد بلاک و ضد شکایت)

این‌ها کد هستند، نه توصیه:

- ارسال انبوه سرد وجود ندارد. پیام اول فقط برای سرنخی ارسال می‌شود که **رضایت (consent)** دارد، مگر اینکه
  اپراتور در همان صفحهٔ سرنخ دکمهٔ «ارسال با تأیید دستی» را بزند (`force`).
- هر پیام باید از فیلترهای زیر رد شود: پنجرهٔ سکوت شبانه، فاصلهٔ تصادفی بین پیام‌ها (پیش‌فرض ۷ تا ۱۸ دقیقه)،
  سقف روزانه (پیش‌فرض ۳۰)، وضعیت «لغو دریافت» و وضعیت سرنخ.
- واژه‌های لغو (`لغو`, `stop`, `unsubscribe`, …) در پیام ورودی، سرنخ را `unsubscribed` می‌کند و
  همهٔ ارسال‌های بعدی را می‌بندد.
- کانال‌های بدون API رسمی (اینستاگرام، ایتا، روبیکا) **دستی** هستند: ایجنت متن را آماده می‌کند،
  شما با یک کلیک کپی و از حساب رسمی خودتان ارسال می‌کنید. هیچ اسکرپ هشتگ/کامنت/دایرکت انجام نمی‌شود.
- قیمت، موجودی و تخفیف فقط از کاتالوگ و تنظیمات فروشگاه خوانده می‌شود؛ مدل اجازهٔ ساختن عدد ندارد
  (سقف تخفیف هم در تنظیمات قفل است).

## گام ۰ — دیتابیس (یک‌بار)

مایگریشن `supabase/migrations/0006_store_agent.sql` را در **Supabase → SQL Editor** اجرا کنید
(یا کل `supabase/all-in-one.sql`). تکرارش بی‌خطر است.

> در همین پروژهٔ Supabase (`auralis`) این مایگریشن قبلاً اعمال شده است؛ اگر پروژهٔ دیگری می‌سازید،
> همین فایل را اجرا کنید. جدول‌ها: `leads`, `lead_events`, `store_messages`, `campaigns`,
> `marketing_posts`, `competitors`, `trend_signals`, `research_reports`, `store_agent_runs`,
> `store_channels`, `store_agent_settings`.

بعد از آن `/control/store` باید بالا بیاید. اگر جدول‌ها نبودند، صفحهٔ خطای فارسی با لینک مستقیم
همین راهنما نمایش داده می‌شود.

## گام ۱ — مغز هوش مصنوعی (رایگان)

1. به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) بروید و یک کلید رایگان بسازید.
2. در `/control/store/settings` فیلد «کلید Gemini» را پر کنید و ذخیره بزنید.
3. مدل پیش‌فرض `gemini-2.0-flash` است؛ اگر کلید شما مدل دیگری دارد، همان را در فیلد مدل بنویسید.

بدون کلید هم همه‌چیز کار می‌کند: متن‌ها از قالب‌های فارسی داخل کد ساخته می‌شوند
(`engine: template`) و در داشبورد با برچسب مشخص می‌شوند. با کلید، کیفیت شخصی‌سازی بالا می‌رود.

کلید در `app_settings` با AES-256-GCM ذخیره می‌شود. `GEMINI_API_KEY` در محیط، اگر ست باشد،
اولویت دارد.

## گام ۲ — تلگرام (کانال اصلی و رایگان)

اگر ربات مرکز کنترل را قبلاً ساخته‌اید، همان کافی است:

1. `/control/settings` → توکن ربات و شناسهٔ چت خودتان را ذخیره کنید (دکمهٔ تست/ثبت وب‌هوک).
2. در `/control/store/settings` کانال «تلگرام» را فعال کنید. توکن از همان تنظیمات مرکز کنترل
   خوانده می‌شود و لازم نیست دوباره وارد شود.
3. برای انتشار خودکار پست در یک کانال/گروه، در فیلد «شناسه/هندل» همان کانال بنویسید
   (`@mychannel` یا `-100…`) و ربات را ادمین کانال کنید.

رفتار ربات:

- پیام مشتری → ساخت/به‌روزرسانی سرنخ → پاسخ پیش‌نویس → اگر اولین پیام گفتگو باشد و
  «خوشامد خودکار» روشن باشد، پاسخ ارسال می‌شود؛ در غیر این صورت کارت تأیید برای شما می‌آید.
- روی کارت تأیید: دکمه‌های **ارسال** / **رد** / **مشاهده**. ریپلای متنی روی همان کارت، متن پیش‌نویس را
  بازنویسی می‌کند و بعد می‌توانید ارسال کنید.
- دستورهای متنی: `sok <id>` ارسال، `sno <id>` رد، `sview <id>` مشاهده.

## کاتالوگ در کانال (عکس + توضیحات + لینک)

صفحهٔ `/control/store/catalog` همهٔ محصولات فعال را به‌صورت پست عکس‌دار در کانال منتشر می‌کند:

- عکس اول محصول از `products.images` (همان عکس سایت) — نیازی به آپلود دوباره نیست.
- کپشن: نام، توضیح کوتاه، قیمت (و قیمت قبل از تخفیف)، موجودی کم، پیشنهاد فروشگاه و
  لینک مستقیم `https://<APP_URL>/products/<slug>`.
- پست‌ها بی‌صدا (`disable_notification`) و با فاصلهٔ چند ثانیه ارسال می‌شوند.
- هر محصول فقط یک‌بار ثبت می‌شود (`store_product_posts` با کلید یکتای محصول + کانال)؛
  دکمهٔ «انتشار محصولات جدید» محصول تکراری نمی‌فرستد و «انتشار مجدد همه» فقط وقتی لازم است
  که بخواهید پست‌ها را از نو بسازید.

پیش‌نیاز: اجرای `supabase/migrations/0007_product_broadcast.sql` (داخل `all-in-one.sql` هم هست)
و تنظیم هندل کانال در `/control/store/settings` + ادمین‌بودن ربات در کانال.

## گام ۳ — کانال‌ها

| کانال | حالت | چه چیزی لازم است |
|---|---|---|
| تلگرام | API | توکن ربات (از مرکز کنترل) + شناسهٔ کانال برای انتشار |
| بله | API | توکن ربات بله؛ `BALE_BOT_TOKEN` در محیط یا فیلد توکن کانال |
| اینستاگرام | دستی | هندل خودتان؛ متن آماده کپی می‌شود (بدون دایرکت انبوه) |
| ایتا | دستی | هندل/کانال؛ متن آماده |
| روبیکا | دستی | هندل/کانال؛ متن آماده |
| وب‌سایت | Webhook | آدرس فرم/لندینگ + کلید مخفی |

برای هر کانال دکمهٔ **تست اتصال** وضعیت واقعی را چک می‌کند (فقط کانال‌های API).

### فرم آمادهٔ سایت (لید مگنت)

فرم واقعی و آماده در صفحهٔ `/guide#magnet` (و لینک «دریافت راهنمای رایگان» در فوتر) قرار دارد.
این فرم به یک endpoint عمومی و امن‌شده وصل است:

```http
POST /api/store/lead-magnet
Content-Type: application/json

{ "name": "سارا", "contact": "0912…", "text": "کیف برای هدیه می‌خواهم" }
```

- بدون کلید مخفی است چون از مرورگر مشتری صدا زده می‌شود؛ در عوض honeypot، سقف طول فیلدها و
  محدودیت ۶ درخواست در ۱۰ دقیقه برای هر IP دارد.
- پاسخ‌ها شناسهٔ داخلی لو نمی‌دهند. سرنخ با `source: website` و `consent: true` ثبت می‌شود،
  پیام خوش‌آمد/راهنما ساخته می‌شود و کارت آن برای شما در تلگرام می‌آید.
- عنوان و لینک راهنما از تنظیمات ایجنت خوانده می‌شود؛ اگر لینک خالی باشد، فرم باز هم کار می‌کند
  و پیام تشکر بدون دکمهٔ دانلود نشان داده می‌شود.

### فرم/وب‌هوک سفارشی (پل اینستاگرام، ایتا، n8n)

مقصد:

```http
POST https://<domain>/api/control/store/inbound?secret=<STORE_AGENT_WEBHOOK_SECRET>
Content-Type: application/json

{ "channel": "website", "name": "سارا", "handle": "sara@example.com",
  "phone": "0912…", "text": "قیمت کیف مرواریدی چنده؟", "source": "website" }
```

- `secret` همان «کلید مخفی وب‌هوک» در تنظیمات ایجنت است (یا `STORE_AGENT_WEBHOOK_SECRET` / `CRON_SECRET`).
- اگر کلید تنظیم نشده باشد، فقط نشست ادمین می‌تواند این endpoint را صدا بزند؛ یعنی هرگز باز نمی‌ماند.
- پاسخ: `{ ok, leadId, created, draftId, autoSent, info }`.
> این endpoint برای **سرور به سرور** است. کلید مخفی را هرگز داخل HTML مرورگر نگذارید؛
> فرم عمومی سایت از `/api/store/lead-magnet` استفاده می‌کند که بالاتر توضیح داده شده است.
> برای اتصال n8n/Make، کلید را در هدر `X-Store-Secret` یا `Authorization: Bearer` بفرستید:

```bash
curl -X POST "https://<domain>/api/control/store/inbound" \
  -H "Content-Type: application/json" \
  -H "X-Store-Secret: $STORE_AGENT_WEBHOOK_SECRET" \
  -d '{"channel":"instagram","name":"سارا","handle":"@sara","text":"قیمت کیف؟","source":"instagram"}'
```

> اگر پل اینستاگرام/ایتا دارید (ManyChat، وبهوک رسمی، n8n)، همان را به این آدرس وصل کنید.
> ایجنت فقط پیام‌هایی را می‌گیرد که کاربر خودش فرستاده است.

## گام ۵ — اولین تست (۵ دقیقه)

1. به ربات تلگرام یک پیام واقعی بفرستید (`سلام، قیمت کیف مرواریدی؟`). باید در
   `/control/store/leads` سرنخ ساخته شود و در «صندوق» پیش‌نویس پاسخ ظاهر شود.
2. `/control/store` → «اجرای ایجنت فروش» را بزنید.
3. `/control/store/inbox` → تب «پیش‌نویس‌ها» → یک پیام را ویرایش و ارسال کنید.
4. `/control/store/leads` → یک سرنخ دستی با رضایت بسازید و «پیام اول» بگیرید.
5. `/control/store/research` → یک گزارش «رقبا» با متن واقعی نظرات/قیمت بسازید.
6. `/control/store/marketing` → یک کمپین بسازید و برای کانال تلگرام پست تولید کنید.

> برای دیدن دادهٔ نمونه در محیط لوکال، `ALLOW_DEMO_SEED=true` را در `.env.local` بگذارید و
> `POST /api/control/store/seed` را با نشست ادمین صدا بزنید. در پروداکشن این کار عمداً قفل است.

## کرون (خودکارسازی)

`vercel.json` دو کرون روزانه دارد (پلن Hobby بیشتر اجازه نمی‌دهد):

- `03:17` — ایجنت فریلنسری قبلی
- `06:23` — `/api/control/store/agent/cron`

برای بازه‌های کوتاه‌تر (پیشنهاد: هر ۱۵ دقیقه) از یک سرویس رایگان مثل cron-job.org یا
GitHub Actions استفاده کنید:

```http
GET https://<domain>/api/control/store/agent/cron?secret=<STORE_AGENT_WEBHOOK_SECRET>&mode=all
```

`mode`: `all` (پیش‌فرض)، `sales`، `marketing`، `research`. اجرای مکرر بی‌خطر است؛ ارکستراتور
فقط کارهای سررسیدشده را انجام می‌دهد و خلاصهٔ روزانه را به تلگرام می‌فرستد (`digest=0` خاموش).

## مرجع API (برای اتصال‌های بعدی)

همهٔ مسیرهای `/api/control/store/**` با نشست ادمین محافظت می‌شوند، مگر موارد نشان‌دار.

| متد و مسیر | کار |
|---|---|
| `GET /api/control/store/overview` | آمار داشبورد |
| `GET/POST /api/control/store/leads` | فهرست / ساخت سرنخ |
| `GET/PATCH /api/control/store/leads/:id` | پرونده / ویرایش |
| `POST /api/control/store/leads/:id/draft` | `{ kind, objective }` → پیش‌نویس |
| `POST /api/control/store/leads/import` | ایمپورت CSV/JSON با رضایت |
| `GET /api/control/store/messages` | صف/پیش‌نویس‌ها |
| `POST /api/control/store/messages` | پیام دستی `{ leadId, body, kind }` |
| `PATCH /api/control/store/messages/:id` | `send\|update\|schedule\|discard\|manual-sent` |
| `POST /api/control/store/research` | `{ action:"run", kind, useSearch, prompt }` |
| `GET/POST/PATCH /api/control/store/campaigns[/:id]` | کمپین‌ها + `generate\|status` |
| `PATCH /api/control/store/posts/:id` | `publish\|schedule\|manual-sent\|update\|archive` |
| `POST /api/control/store/agent` | اجرای دستی ایجنت `{ agent }` |
| `GET /api/control/store/agent/cron` * | کرون (secret یا Vercel یا ادمین) |
| `POST /api/control/store/inbound` * | فرم/وب‌هوک ورودی (secret یا ادمین) |
| `POST /api/control/store/seed` | داده نمونه (نیازمند `ALLOW_DEMO_SEED=true`) |

\* عمومی‌شده فقط با کلید مخفی.
