## بازسازی تصاویر

تصاویر با `tools/social-shots/` ساخته می‌شوند (متن فارسی با HarfBuzz شکل می‌گیرد و
به‌صورت path رسم می‌شود، پس ترتیب کلمات و اتصال حروف درست است).

ابعاد فعلی: ۹۰۰ پیکسل عرض و ضلع بلند نزدیک ۱۲۸۰ پیکسل — تلگرام عکس را تا ضلع
بلند ~۱۲۸۰ کوچک می‌کند، در این اندازه متن روی گوشی خوانا می‌ماند.

```bash
pip3 install uharfbuzz fonttools pillow && npm i vazirmatn
python3 tools/social-shots/make.py      # خروجی در /tmp/tg/out
```
